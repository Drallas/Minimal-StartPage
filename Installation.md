# Installation

Minimal-StartPage is a single web page: `index.html` with its CSS and JavaScript. There is nothing to build or install.

## Use it as your homepage

1. Download the source: click **Code → Download ZIP** on GitHub, or run `git clone https://github.com/Drallas/Minimal-StartPage.git`.
2. Extract the folder somewhere you will keep it.
3. Open `index.html` in your browser to check that it works.
4. Set your browser's homepage to that file, for example:
   - Windows: `file:///C:/path/to/Minimal-StartPage/index.html`
   - macOS or Linux: `file:///path/to/Minimal-StartPage/index.html`

The exact place to set the homepage depends on your browser. Look for **Home** or **On startup** in its settings.
